
# VisionMate – AI-Powered Accessibility Assistant

## About the Project
VisionMate is an AI-powered accessibility assistant designed to help visually impaired users understand images through simple text descriptions.

## Features
- Upload an image for analysis
- Generate an AI-based image description
- Identify objects, people, and readable text
- Listen to the description using text-to-speech
- Simple and accessible user interface

## Technologies Used
- Python
- Streamlit
- Google Gemini API

## How to Run
1. Install Python.
2. Install the required packages:
   `python -m pip install -r requirements.txt`
3. Configure your API key in the `.env` file.
4. Start the application:
   `python -m streamlit run app.py`

## Project Purpose
To make visual information more accessible to people with visual impairments.
